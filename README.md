# 💻 Studies in C Language

Repositório dedicado aos meus estudos e exercícios desenvolvidos em linguagem C durante minha formação em Engenharia de Software.

Este espaço reúne práticas de lógica de programação, estruturas fundamentais da linguagem e resolução de problemas acadêmicos para fortalecer minha base em programação e raciocínio computacional.

## 🚀 Tecnologias utilizadas

- Dev-C++
- GCC
- Git & GitHub
